# Roteiro de teste no iPhone (celular de referência)

Para Guto, no próprio iPhone, depois do deploy. São cerca de 15 minutos. Anote o modelo e a versão do iOS (Ajustes → Geral → Sobre) e marque cada item com ✓ ou ✗. Se marcar ✗, descreva o que viu ou tire um print.

Aparelho: __________ · iOS: ______ · Data: ______

## 1. Básico no Safari
- [ ] Abrir o site, criar a conta ou entrar. A tela de Hoje aparece sem nada cortado no entalhe nem na barra inferior.
- [ ] Rolar Hoje, Estudar e Redação: nenhuma página rola para os lados.
- [ ] Girar o iPhone (deitado): nada fica escondido atrás do entalhe.
- [ ] Ao tocar no campo de e-mail ou senha, a tela **não** dá zoom sozinha.

## 2. Toque
- [ ] Hoje → Começar: o cartão abre a tela de foco sem travar. Encerrar volta ao histórico.
- [ ] Arrastar um bloco da agenda para outro horário funciona. Tocar no bloco abre "Remarcar".
- [ ] Estudar: tocar numa alternativa, Confirmar, Ver Raio-X. Os botões são fáceis de acertar com o polegar.
- [ ] Redação: as cinco abas C1–C5 cabem na largura e respondem ao toque.

## 3. Teclado virtual
- [ ] Na tela Entrar, com o teclado aberto, o botão Entrar continua alcançável (rolando, se precisar).
- [ ] O teclado oferece "@" e ".com" no campo de e-mail.

## 4. VoiceOver (Ajustes → Acessibilidade → VoiceOver, ou triplo clique no botão lateral se estiver configurado)
- [ ] Deslizar para a direita percorre Hoje numa ordem que faz sentido (título, próximo bloco, botões).
- [ ] Na questão, cada alternativa é lida com a letra e o texto. Depois de confirmar, "Correta" e "Sua resposta" são anunciados.
- [ ] Na agenda, cada bloco é lido com o título, o horário e "Ativar para remarcar".
- [ ] Na Redação, cada aba é lida com o código e o nome da competência ("C3 120 Argumentação").

## 5. Movimento reduzido (Ajustes → Acessibilidade → Movimento → Reduzir movimento)
- [ ] Com a opção ligada, Começar foco e Ver Raio-X mudam de tela sem animações de deslocamento.

## 6. Desempenho percebido
- [ ] Abrir Hoje pela primeira vez leva menos de 3 segundos no 4G/5G.
- [ ] As animações de foco e de passagem não engasgam.
